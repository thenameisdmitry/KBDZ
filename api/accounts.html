Accounts

Create and manage Accounts in your environment. The API supports full CRUD operations.

For Account management, Account parameters, and reference data in the DZ environment, see the Reference Data User Guide. Pagination, filtering, and idempotency work the same way here as everywhere else: see Conventions and Errors.

GET/accounts

List accounts

Returns a paginated list of Accounts. Filter by status to narrow results.

Query parameters
ParameterTypeRequiredDescription
limitintegerOptionalResults per page. Default: 20. Maximum: 100.
offsetintegerOptionalResults to skip before the page starts. Default: 0.
statusstringOptionalFilter by Account status. One of: active, suspended, closed.
Request
curl -X GET "https://api.dzenterprise.io/v1/accounts?limit=20&offset=0&status=active" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json"
Response fields
FieldTypeDescription
dataarrayThe page of Account objects. Empty when nothing matches, never null.
totalintegerTotal Accounts matching the filter, across all pages.
limitintegerThe limit applied to this response, after clamping to 100.
offsetintegerThe offset applied to this response.
Response200 OK

GET/accounts/{id}

Get account by ID

Retrieves the full details of a single Account by its unique identifier.

Path parameters
ParameterTypeRequiredDescription
idstringRequiredThe unique Account ID, for example acc_007.
Request
curl -X GET "https://api.dzenterprise.io/v1/accounts/acc_007" \
  -H "Authorization: Bearer {access_token}"
Response fields: Account object
FieldTypeDescription
idstringUnique Account identifier. Opaque, do not parse it.
owner_idstringIdentifier of the user who owns this Account.

statusstringOne of: active, suspended, closed.
created_atstringRFC 3339 timestamp in UTC.
updated_atstringRFC 3339 timestamp in UTC of the last change.

POST/accounts

Create account

Creates an Account for the specified owner and returns the created resource.

Request body
ParameterTypeRequiredDescription
owner_idstringRequiredID of the user who owns this Account.
namestringRequiredHuman-readable label for the Account.
typestringRequiredAccount type. One of: trading, operating, custody, fee. Cannot be changed later.
currencystringRequiredISO 4217 currency code, for example USD, EUR, GBP. Cannot be changed later.

Send an Idempotency-Key header so a retry after a timeout returns the original Account instead of creating a second one.

Request
curl -X POST "https://api.dzenterprise.io/v1/accounts" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 5f2b8c14-9d7a-4e31-b6c0-1a2f3e4d5c6b" \
  -d '{
    "owner_id": "james_b",
    "name": "Main Trading Account",
    "type": "trading",
    "currency": "USD"
  }'
Response fields: Account object
FieldTypeDescription
idstringUnique Account identifier. Opaque, do not parse it.
owner_idstringIdentifier of the user who owns this Account.
namestringHuman-readable label shown in the UI.
typestringPurpose the Account serves. One of: trading, operating, custody, fee. Fixed at creation.
currencystringISO 4217 code. Fixed at creation.
balancenumberCurrent balance in the major unit of currency.
statusstringOne of: active, suspended, closed.
created_atstringRFC 3339 timestamp in UTC.
updated_atstringRFC 3339 timestamp in UTC of the last change.
Response201 Created

PATCH/accounts/{id}

Update account

Partially updates an Account. Only the fields you send are modified.

Path parameters
ParameterTypeRequiredDescription
idstringRequiredThe unique Account ID.
Request body
ParameterTypeRequiredDescription
namestringOptionalNew display name for the Account.
statusstringOptionalNew status. One of: active, suspended, closed.

type and currency are fixed at creation. Sending either returns 422 validation_failed.

Request
curl -X PATCH "https://api.dzenterprise.io/v1/accounts/acc_007" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"name": "Primary Custodian Account", "status": "active"}'
Response fields: Account object
FieldTypeDescription
idstringUnique Account identifier. Opaque, do not parse it.
owner_idstringIdentifier of the user who owns this Account.
namestringHuman-readable label shown in the UI.
typestringPurpose the Account serves. One of: trading, operating, custody, fee. Fixed at creation.
currencystringISO 4217 code. Fixed at creation.
balancenumberCurrent balance in the major unit of currency.
statusstringOne of: active, suspended, closed.
created_atstringRFC 3339 timestamp in UTC.
updated_atstringRFC 3339 timestamp in UTC of the last change.
Response200 OK
{

DELETE/accounts/{id}

Remove account

Permanently deletes an Account and all its associated data. This action cannot be undone.

Path parameters
ParameterTypeRequiredDescription
idstringRequiredThe unique Account ID to delete.

An Account that still holds an open Position returns 409 conflict. Close the Position first, then retry.

Request
curl -X DELETE "https://api.dzenterprise.io/v1/accounts/acc_007" \
  -H "Authorization: Bearer {access_token}"
Response204 No Content
// No body returned
