Credit Agreements

Create and manage Credit Agreements linked to your Accounts. Each Agreement captures the legal and financial terms of a credit facility established between your organisation and a counterparty.

Credit Agreements are scoped to an Account and are independent of Portfolios. A single Account may have multiple Credit Agreements with different counterparties, currencies, and maturity profiles.

GET/agreements

List credit agreements

Returns a paginated list of Credit Agreements. Filter by account, status, or type to narrow results.

Query parameters
ParameterTypeRequiredDescription
limitintegerOptionalNumber of results to return. Default: 20, max: 100.
offsetintegerOptionalNumber of results to skip. Use for pagination. Default: 0.
account_idstringOptionalFilter agreements by the associated account ID.
statusstringOptionalFilter by status. One of: active, expired, terminated, pending.
typestringOptionalFilter by agreement type. One of: credit, collateral, master.
Request
curl -X GET "https://api.dzenterprise.io/v1/agreements?limit=20&offset=0&status=active" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json"

POST/agreements

Create credit agreement

Creates a new Credit Agreement for the specified account. Returns the created resource.

Request body
ParameterTypeRequiredDescription
account_idstringRequiredID of the Account this agreement is linked to.
typestringRequiredAgreement type. One of: credit, collateral, master.
namestringRequiredDescriptive name identifying the agreement and counterparty.
principal_amountnumberRequiredTotal principal amount of the credit facility.
currencystringRequiredISO 4217 currency code (e.g. GBP, USD, EUR).
interest_ratenumberRequiredAnnual interest rate as a percentage (e.g. 4.25 for 4.25%).
start_datestringRequiredAgreement start date. Format: YYYY-MM-DD.
maturity_datestringRequiredAgreement maturity date. Format: YYYY-MM-DD.
Request
curl -X POST "https://api.dzenterprise.io/v1/agreements" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "account_id": "acc_007",
    "type": "credit",
    "name": "Credit Agreement — BHMS / BNP Paribas",
    "principal_amount": 50000000.00,
    "currency": "GBP",
    "interest_rate": 4.25,
    "start_date": "2026-01-15",
    "maturity_date": "2031-01-15"
  }'
Response201 Created

PATCH/agreements/{id}

Update credit agreement

Partially updates a Credit Agreement. Only supplied fields are modified. account_id, currency, and type cannot be changed after creation.

Path parameters
ParameterTypeRequiredDescription
idstringRequiredThe unique agreement ID.
Request body
ParameterTypeRequiredDescription
namestringOptionalUpdated agreement name.
principal_amountnumberOptionalUpdated principal amount.
interest_ratenumberOptionalUpdated annual interest rate.
maturity_datestringOptionalUpdated maturity date. Format: YYYY-MM-DD.
statusstringOptionalUpdated status. One of: active, expired, terminated, pending.
Request
curl -X PATCH "https://api.dzenterprise.io/v1/agreements/agr_BNP_001" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"interest_rate": 4.50, "status": "active"}'
Response200 OK

DELETE/agreements/{id}

Remove credit agreement

Permanently deletes a Credit Agreement. Only agreements with status pending or terminated can be deleted.

Path parameters
ParameterTypeRequiredDescription
idstringRequiredThe unique agreement ID to delete.
Request
curl -X DELETE "https://api.dzenterprise.io/v1/agreements/agr_BNP_001" \
  -H "Authorization: Bearer {access_token}"
Response204 No Content
