Custodians

Create and manage Custodians in your environment. The API supports full CRUD operations.

A Custodian is the institution that holds your assets: a custodian bank, a prime broker, a clearing house, a commercial bank, or a fund administrator. Every Account is opened at a Custodian, and Custodian records supply the routing details that Payments settle through. Pagination, filtering, and idempotency follow the shared Conventions.

GET/custodians

List custodians

Returns a paginated list of Custodians. Filter by institution type, country, or status to narrow results.

Query parameters
ParameterTypeRequiredDescription
institution_typestringOptionalFilter by institution type. One of: custodian_bank, prime_broker, clearing_house, commercial_bank, fund_administrator.
countrystringOptionalFilter by ISO 3166-1 alpha-2 country code, for example FR.
statusstringOptionalFilter by status. One of: active, suspended, inactive.
limitintegerOptionalResults per page. Default: 20. Maximum: 100.
offsetintegerOptionalResults to skip before the page starts. Default: 0.
Request
curl -X GET "https://api.dzenterprise.io/v1/custodians?institution_type=custodian_bank&limit=20" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json"
Response fields
FieldTypeDescription
dataarrayThe page of Custodian objects. Empty when nothing matches, never null.
totalintegerTotal Custodians matching the filter, across all pages.
limitintegerThe limit applied to this response, after clamping to 100.
offsetintegerThe offset applied to this response.

Retrieves the full details of a single Custodian by its unique identifier.

idstringRequiredThe unique Custodian ID, for example cus_BNP_001.
Request
curl -X GET "https://api.dzenterprise.io/v1/custodians/cus_BNP_001" \

POST/custodians

Create custodian

Registers a Custodian in your environment and returns the created resource.

Request body
ParameterTypeRequiredDescription
namestringRequiredFull legal name of the institution.
codestringRequiredShort internal code, upper case. Must be unique across the environment.
institution_typestringRequiredKind of institution. One of: custodian_bank, prime_broker, clearing_house, commercial_bank, fund_administrator.
bicstringOptionalSWIFT BIC, 8 or 11 characters. Required before the Custodian can settle SWIFT Payments.
countrystringRequiredISO 3166-1 alpha-2 country code of the registered entity.
contact_emailstringOptionalOperations mailbox used for reconciliation queries.

A new Custodian starts with status: active. Reusing an existing code returns 409 conflict.

Request
curl -X POST "https://api.dzenterprise.io/v1/custodians" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: b91f0d47-2c6e-4a35-8f71-0e4c9a3b6d28" \
  -d '{
    "name": "BNP Paribas Securities Services",
    "code": "BNPPSS",
    "institution_type": "custodian_bank",
    "bic": "PARBFRPP",
    "country": "FR",
    "contact_email": "custody.ops@example-bnp.com"
  }'

PATCH/custodians/{id}

Update custodian

Partially updates a Custodian. Only the fields you send are modified.

Path parameters
ParameterTypeRequiredDescription
idstringRequiredThe unique Custodian ID.
Request body
ParameterTypeRequiredDescription
namestringOptionalUpdated legal name of the institution.
bicstringOptionalUpdated SWIFT BIC.
contact_emailstringOptionalUpdated operations mailbox. Send null to clear it.
statusstringOptionalNew status. One of: active, suspended, inactive.

code, institution_type, and country are fixed at creation, because downstream feed files and settlement instructions are keyed on them. Sending any of them returns 422 validation_failed. Setting a Custodian to suspended blocks new Accounts and Payments but leaves existing ones untouched.

Request
curl -X PATCH "https://api.dzenterprise.io/v1/custodians/cus_BNP_001" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"contact_email": "custody.emea@example-bnp.com", "status": "active"}'

DELETE/custodians/{id}

Remove custodian

Permanently deletes a Custodian. This action cannot be undone.

Path parameters
ParameterTypeRequiredDescription
idstringRequiredThe unique Custodian ID to delete.

A Custodian that still has Accounts or unsettled Payments returns 409 conflict. To retire an institution while keeping its history, set status to inactive instead of deleting it.

Request
curl -X DELETE "https://api.dzenterprise.io/v1/custodians/cus_BNP_001" \
  -H "Authorization: Bearer {access_token}"
Response204 No Content
// No body returned
