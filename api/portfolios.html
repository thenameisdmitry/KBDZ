Portfolios

Create and manage Portfolios within your environment. API supports full CRUD operations.

Portfolios aggragate assets from one or more Accounts. Each portfolio tracks its own total value, currency, and investment strategy. To learn more about Portfolios and how to assemble them accross the DZ environment, proceed to the Reference Data User Guide.

GET/portfolios

List portfolios

Returns a paginated list of portfolios. Filter by portfolio id, strategy, or status to narrow results.

Query parameters
ParameterTypeRequiredDescription
portfolio_idstringOptionalFilter portfolios by their unique identificator.
strategystringOptionalFilter by strategy. One of: conservative, moderate, aggressive.
statusstringOptionalFilter by status. One of: active, paused, closed.
limitintegerOptionalNumber of results to return. Default: 20, max: 100.
offsetintegerOptionalPagination offset. Default: 0.
Request
curl -X GET "https://api.dzenterprise.io/v1/portfolios?portfolio_id=prt_BNPParibas_001&limit=20" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json"

POST/portfolios

Create portfolio

Creates a new portfolio under the specified account.

Request body
ParameterTypeRequiredDescription
portfolio_idstringRequiredUnique identifier of the Portfolio.
namestringRequiredDescriptive name for the portfolio.
strategystringRequiredInvestment strategy. One of: conservative, moderate, aggressive.
currencystringRequiredISO 4217 base currency for the portfolio.
accountsarrayOptionalList of accounts investing in this portfolio. Each item contains: id (string), allocation_pct (number).
accounts[].idstringRequiredUnique identifier of the account.
accounts[].allocation_pctnumberRequiredPercentage of the portfolio allocated to this account. All values must sum to 100.
Note: The accounts[].id and accounts[].allocation_pct fields are required only when the accounts array is provided. If omitted, the portfolio is created with no associated accounts.
Request
curl -X POST "https://api.dzenterprise.io/v1/portfolios" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "portfolio_id": "prt_BNPParibas_001",
    "name": "BHMS Portfolio BNP Paribas",
    "strategy": "loan benchmarking",
    "currency": "GBP",
    "accounts": [
      { "id": "acc_007", "allocation_pct": 50.00 },
      { "id": "acc_019", "allocation_pct": 30.00 }
    ]
  }'
Response201 Created

DELETE/portfolios/{id}

Remove portfolio

Permanently deletes a portfolio. All associated holdings records will also be removed.

Path parameters
ParameterTypeRequiredDescription
portfolio_idstringRequiredUnique portfolio ID to delete.
Request
curl -X DELETE "https://api.dzenterprise.io/v1/portfolios/prt_BNPParibas_001" \
  -H "Authorization: Bearer {access_token}"
Response204 No Content
