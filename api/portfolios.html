Portfolios

Create and manage Portfolios in your environment. The API supports full CRUD operations.

A Portfolio aggregates assets from one or more Accounts and tracks its own total value, currency, and investment strategy. To learn more about assembling Portfolios in the DZ environment, see the Reference Data User Guide. Pagination, filtering, and idempotency follow the shared Conventions.

GET/portfolios

List portfolios

Returns a paginated list of Portfolios. Filter by strategy or status to narrow results.

Query parameters
ParameterTypeRequiredDescription
strategystringOptionalFilter by investment strategy label, for example "loan benchmarking".
statusstringOptionalFilter by status. One of: active, paused, closed.
limitintegerOptionalResults per page. Default: 20. Maximum: 100.
offsetintegerOptionalResults to skip before the page starts. Default: 0.
Request
curl -X GET "https://api.dzenterprise.io/v1/portfolios?strategy=loan%20benchmarking&limit=20" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json"
Response fields
FieldTypeDescription
dataarrayThe page of Portfolio objects. Empty when nothing matches, never null.
totalintegerTotal Portfolios matching the filter, across all pages.
limitintegerThe limit applied to this response, after clamping to 100.
offsetintegerThe offset applied to this response.

POST/portfolios

Create portfolio

Creates a Portfolio and attaches the supplied Account allocations.

Request body
ParameterTypeRequiredDescription
namestringRequiredDescriptive name for the Portfolio.
strategystringRequiredInvestment strategy label, for example "loan benchmarking".
currencystringRequiredISO 4217 base currency. Cannot be changed later.
accountsarrayOptionalAccounts investing in this Portfolio. Omit to create an empty Portfolio.
accounts[].idstringRequiredUnique identifier of the Account. Required when accounts is supplied.
accounts[].allocation_pctnumberRequiredShare of the Portfolio held in this Account. All values must sum to exactly 100.
Note: portfolio_id is generated by the API and must not be sent. The fields inside accounts[] are required only when the accounts array is supplied; if it is omitted, the Portfolio is created with no allocations. Allocations that do not sum to 100 are rejected with 422 validation_failed.
Request
curl -X POST "https://api.dzenterprise.io/v1/portfolios" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 7c1d4a90-3b52-4f88-9e10-6d5a2b7c8e41" \
  -d '{
    "name": "BHMS Portfolio BNP Paribas",
    "strategy": "loan benchmarking",
    "currency": "GBP",
    "accounts": [
      { "id": "acc_007",  "allocation_pct": 58.93 },
      { "id": "acc_8901", "allocation_pct": 41.07 }
    ]
  }'
Response fields: Portfolio object

statusstringOne of: active, paused, closed.
accountsarrayAccounts allocated to this Portfolio. See the allocation object below.
created_atstringRFC 3339 timestamp in UTC.
updated_atstringRFC 3339 timestamp in UTC of the last change.
Response201 Created

PATCH/portfolios/{portfolio_id}

Update portfolio

Partially updates a Portfolio. Only the fields you send are modified.

Path parameters
ParameterTypeRequiredDescription
portfolio_idstringRequiredUnique Portfolio ID.
Request body
ParameterTypeRequiredDescription
namestringOptionalNew display name for the Portfolio.
strategystringOptionalUpdated investment strategy label.
statusstringOptionalNew status. One of: active, paused, closed.

Allocations are not editable here. Change them by updating the Accounts attached to the Portfolio, so the sum can be revalidated as a whole.

Request
curl -X PATCH "https://api.dzenterprise.io/v1/portfolios/prt_BNPParibas_001" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"name": "BHMS Core Growth Portfolio", "strategy": "moderate"}'
Response fields: Portfolio object

updated_atstringRFC 3339 timestamp in UTC of the last change.

DELETE/portfolios/{portfolio_id}

Remove portfolio

Permanently deletes a Portfolio and all its holdings records.

Path parameters
ParameterTypeRequiredDescription
portfolio_idstringRequiredUnique Portfolio ID to delete.

A Portfolio with unsettled Transactions returns 409 conflict. The Accounts themselves are not deleted.

Request
curl -X DELETE "https://api.dzenterprise.io/v1/portfolios/prt_BNPParibas_001" \
  -H "Authorization: Bearer {access_token}"
Response204 No Content
// No body returned
