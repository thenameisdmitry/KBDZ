REST API for the DZ Enterprise treasury platform.

This specification is a portfolio artifact: it describes a fictional API and no
live server implements it. It exists to show how I model an API contract in
OpenAPI and generate reference documentation from it.

The hand-written reference at `/api` and this specification describe the same
surface. Read the hand-written pages for narrative and worked examples, and this
file for the machine-readable contract.

## Conventions

- All requests and responses use `application/json`.
- Collections are paged with `limit` and `offset` and return a `data`/`total` envelope.
- Timestamps are RFC 3339 in UTC. Dates are ISO 8601 without a time component.
- Monetary amounts are decimals in the major unit, always paired with a currency code.
- Every `POST` accepts an `Idempotency-Key` header so a retry cannot create a duplicate.
