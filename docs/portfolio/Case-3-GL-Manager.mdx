# Case 3: Getting Started with GL Manager

**Format:** A Getting Started guide designed to introduce readers to the key features of the GL Manager screen, supplemented with real business use cases. The article walks users through the interface and explains core functionality.

**Description:** An onboarding article for the GL Manager screen, which is part of the Transaction Manager module. The guide helps new and existing users orient quickly within the interface. and understand common practices.

**Business impact:** GL Manager brings full transparency to ledger records within a unified system, giving users a single point of visibility across their accounting data. This allows accountants, analysts, and operations staff to immediately identify discrepancies in their own accounting systems or their banking counterparty's records and react immediately.

**Target readers:** Fund accountants, general ledger accountants, financial controllers, and NAV reporting specialists.
