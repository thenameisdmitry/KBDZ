## Images

### Standard image — full width
```mdx
![Alt text](/img/your-folder/image.png)
```

### Standard image — reduced size
```mdx
<div style={{ maxWidth: '350px' }}>

![Alt text](/img/your-folder/image.png)

</div>
```

### Lightbox image — clickable to expand
```mdx
<LightboxImage
  src="/img/your-folder/image.png"
  alt="Alt text"
/>
```

### Lightbox image — reduced size, clickable to expand
```mdx
<LightboxImage
  src="/img/your-folder/image.png"
  alt="Alt text"
  style={{ maxWidth: '350px' }}
/>
```

## Links

### External link
```mdx
[Link text](https://example.com)
```

### Internal page link
```mdx
[Link text](/docs/portfolio/Case-1-Algo-Recon)
```

### Anchor link (jump to heading on same page)
```mdx
[Link text](#heading-in-lowercase-with-hyphens)
```

### Anchor link (jump to heading on another page)
```mdx
[Link text](/docs/portfolio/Case-1-Algo-Recon#heading-anchor)
```
