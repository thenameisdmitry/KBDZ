<Release version="2.4.0" date="June 2026">

<Module name="Algorithmic Security Recon" />

<ReleaseItem type="NEW">
  <strong>Not Mapped Securities screen.</strong> Introduces a dedicated screen providing visibility into Securities extracted from incoming feed files that fell outside all Position search spaces during Algorithmic Reconciliation. Reprocessing can be initiated directly from the screen. See <a href="/docs/portfolio/Case-1-Algo-Recon#not-mapped-securities">Algorithmic Recon Guide →</a>
</ReleaseItem>

<ReleaseItem type="FIX">
  <strong>Unmap Security confirmation.</strong> The Unmap Security action now requires explicit confirmation before execution, preventing accidental unmapping of reconciled Securities.
</ReleaseItem>

<Module name="Approver" />

<ReleaseItem type="FEATURE">
  <strong>Access Code length and Login attempts.</strong> Two new Company Preference settings - Mobile Device Pin Length and Mobile Device Login Attempts - allow administrators to define Access Code length and maximum login attempt limits for mobile users. See <a href="/docs/portfolio/Case-2-Approver-App#access-code-length-and-login-attempts">Approver App Guide →</a>
</ReleaseItem>

<Module name="GL Manager" />

<ReleaseItem type="NEW">
  <strong>User Defined Fields (UDFs) support.</strong> The GL Manager now supports UDFs, allowing users to add and remove custom fields within GL entries to accommodate organisation-specific data requirements. See <a href="/docs/portfolio/Case-3-GL-Manager#gl-user-defined-fields">GL Manager Guide →</a>
</ReleaseItem>

</Release>

<Release version="2.3.0" date="March 2026">

<Module name="GL Manager" />

<ReleaseItem type="NEW">
  <strong>Export and Import Allocation Rules.</strong> Allocation Rules can now be exported and imported in JSON format, enabling consistent rule configuration across environments without manual re-entry. See <a href="/docs/portfolio/Case-3-GL-Manager#gl-allocation-rules">GL Manager Guide →</a>
</ReleaseItem>

<Module name="Optimizer" />

<ReleaseItem type="NEW">
  <strong>Expression Map in Algo Editor.</strong> The Algo Editor now includes an Expression Map - a miniature interactive overview of the Expression field that enables rapid navigation through large code sheets without scrolling. See <a href="/docs/portfolio/Case-4-Optimizer#editor">Optimizer Guide →</a>
</ReleaseItem>

<ReleaseItem type="FEATURE">
  <strong>Blotter run notification.</strong> The Blotter screen now displays a colour-coded Notification Plate upon Solution run completion. A green plate indicates a successful run; a red plate indicates an interruption. Provides immediate status visibility without requiring manual log review.
</ReleaseItem>

</Release>

---

<Release version="2.2.0" date="December 2025">

<Module name="Algorithmic Security Recon" />

<ReleaseItem type="NEW">
  <strong>Rejected Mappings screen.</strong> Introduces the Rejected Mappings screen, consolidating Security mappings from the Weak certainty group that were rejected on the Security Analysis screen. Provides a dedicated audit trail for mapping decisions. See <a href="/docs/portfolio/Case-1-Algo-Recon#rejected-mappings">Algorithmic Recon Guide →</a>
</ReleaseItem>

<Module name="Approver" />

<ReleaseItem type="FIX">
  <strong>Mandatory approval note.</strong> A supplementary note is now required before confirming Voucher approval or rejection. This change aligns with compliance requirements of financial institutions executing Transaction orders.
</ReleaseItem>

</Release>
