# Knowledge Base Guides
This section presents documentation I wrote for the Hazeltree platform as a Senior 
Technical Writer. The samples come from several product modules and cover the range of 
documentation types that enterprise users and implementation teams rely on: knowledge 
base guides, product overviews, getting-started articles, and step-by-step 
implementation instructions.

Each one takes a different approach to the same underlying problem — presenting complex 
functionality so that a reader can act on it.

:::note Confidentiality Notice

Hazeltree's confidentiality requirements limit how much business and product context 
these samples can carry.

Company-specific information and sensitive implementation details have been removed, blurred, 
anonymized, or generalized. The samples still preserve the original structure, writing style, 
and technical depth.
:::
