# Knowledge Base Guides
This section showcases a selection of documentation created for the Hazeltree platform 
as part of a Senior Technical Writer role. The samples are drawn from multiple product 
modules and demonstrate a range of documentation types developed to support enterprise 
users and implementation teams.

Included are knowledge base guides, product overviews, getting-started articles, and 
step-by-step implementation instructions. Together, they illustrate different 
approaches to presenting complex functionality.

:::note Confidentiality Notice

Due to Hazeltree's strict confidentiality requirements, the samples included in this 
portfolio contain limited business and product context.

Company-specific information and sensitive implementation details have been removed, blurred, 
anonymized, or generalized. Still the examples preserve the original documentation 
structure, writing style, and technical depth while respecting confidentiality 
obligations.
:::
