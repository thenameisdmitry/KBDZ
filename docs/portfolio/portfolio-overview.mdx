## Portfolio: Documentation, Code, Release Notes

This portfolio collects writing samples from my most recent role at **Hazeltree**, a fintech SaaS 
platform for treasury management: cash optimization, portfolio profitability analysis, and 
financial risk management.

The examples show how I turn complex product capabilities, workflows, and technical concepts into 
clear, concise, user-focused documentation. Together, they cover the range of content I delivered as a 
**Senior Technical Writer** and writing team lead.

### 📘 Product Documentation

Examples of [customer-facing documentation](./), including:

- Knowledge Base standard guides
- Getting Started With guides
- Conceptual overviews
- Step-by-step implementation instructions

Each sample opens with a short summary that gives the context: intended audience, documentation 
objectives, and the business and compliance constraints it was written under.

### 🐍 Documentation Engineering

The portfolio includes a [Python automation script](./code-samples) that I designed and built to 
streamline release note creation.

The script pulls release information from TFS queries and consolidates it into a single structured 
file, removing hours of manual collection from every release cycle.

### 🚀 Release Notes Strategy

The portfolio also contains a [release notes sample](./releasenotes) that shows my approach to release 
communication and delivery.

It illustrates how I structure release information to improve readability, highlight customer 
impact, surface the changes that matter, and give stakeholders something they can act on.
