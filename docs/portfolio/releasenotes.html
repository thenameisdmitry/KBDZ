Release Notes

This page documents product updates, new features, improvements, and bug fixes across releases. Where relevant, items are linked to the corresponding documentation guides.

v2.4.0June 2026

Algorithmic Security Recon

NEW

Not Mapped Securities screen. Introduces a dedicated screen providing visibility into Securities extracted from incoming feed files that fell outside all Position search spaces during Algorithmic Reconciliation. Reprocessing can be initiated directly from the screen. See Algorithmic Recon Guide →

FIX

Unmap Security confirmation. The Unmap Security action now requires explicit confirmation before execution, preventing accidental unmapping of reconciled Securities.

Approver

FEATURE

Access Code length and Login attempts. Two new Company Preference settings - Mobile Device Pin Length and Mobile Device Login Attempts - allow administrators to define Access Code length and maximum login attempt limits for mobile users. See Approver App Guide →

GL Manager

NEW

User Defined Fields (UDFs) support. The GL Manager now supports UDFs, allowing users to add and remove custom fields within GL entries to accommodate organisation-specific data requirements. See GL Manager Guide →

v2.3.0March 2026

GL Manager

NEW

Export and Import Allocation Rules. Allocation Rules can now be exported and imported in JSON format, enabling consistent rule configuration across environments without manual re-entry. See GL Manager Guide →

Optimizer

NEW

Expression Map in Algo Editor. The Algo Editor now includes an Expression Map - a miniature interactive overview of the Expression field that enables rapid navigation through large code sheets without scrolling. See Optimizer Guide →

FEATURE

Blotter run notification. The Blotter screen now displays a colour-coded Notification Plate upon Solution run completion. A green plate indicates a successful run; a red plate indicates an interruption. Provides immediate status visibility without requiring manual log review.

v2.2.0December 2025

Algorithmic Security Recon

NEW

Rejected Mappings screen. Introduces the Rejected Mappings screen, consolidating Security mappings from the Weak certainty group that were rejected on the Security Analysis screen. Provides a dedicated audit trail for mapping decisions. See Algorithmic Recon Guide →

Approver

FIX

Mandatory approval note. A supplementary note is now required before confirming Voucher approval or rejection. This change aligns with compliance requirements of financial institutions executing Transaction orders.
